# Pizza Dough Calculator — Geek Edition

Fully client-side pizza dough calculator (no server required).

## Features
- Scientific yeast model (Q10 temperature dependence + optional salt factor)
- Craig (TXCraig1) current formulas and process notes
- Multi-stage fermentation equivalent-time calculator
- Final Dough Temperature / water temperature calculator
- Preferment calculator (Poolish / Biga / Sourdough)
- Local recipe library (localStorage) with import/export
- Reverse calculation from flour weight
- Geek metrics and sensitivity tools
- Process notes and science library

## Usage
Open `index.html` in any modern browser. Works offline.

## Source
Based on research of Craig's Neapolitan Garage (pizzamaking.com), AVPN standards, and fermentation science literature.
